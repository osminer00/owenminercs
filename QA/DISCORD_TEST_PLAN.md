# Discord Website Testing Plan

## Goal

Run a short community test round to catch broken links, layout bugs, and unclear wording before wider rollout.

## Tester Instructions (copy/paste)

Please test on any device/browser you have and report issues in Discord using:

- Page URL:
- Device + browser:
- What you did:
- What happened:
- What you expected:
- Screenshot/video:

## Priority Areas

- Home page and top navigation
- Setup pages (`The Setup`, `Desk Setup`, `Keyboard`, `PC`)
- Gaming tools/pages (`Gaming`, CS2 pages, calculators)
- Donators, Q&A, Socials, and Services pages
- Footer links and external links opening correctly

## Pass/Fail Checks

- No page shows placeholder/dev-only copy
- No broken HTML pages
- Forms/tools that are read-only clearly say so
- Mobile layout is readable (no clipped text/buttons)
- Main call-to-action links work (Discord invite, Social links, shop/support links)

## Wrap-Up

After collecting reports, group fixes by:

1. Critical breakages (broken pages, scripts, or dead links)
2. UX issues (confusing wording, poor mobile spacing)
3. Nice-to-have polish
