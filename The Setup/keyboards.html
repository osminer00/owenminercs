Kilowatt keyboard breakdown

Currently, I'm using the Tofu 60 Redux (e-coating orange). This case is much less deep than the aluminum GH60 from AliExpress that I previously used. That means a lot less room for sound dampening material. In this build I'm just using the included foam that comes with the Tofu Redux. To add custom flair, I photoshopped and printed the Kilowatt case logo onto acrylic sticker paper for the front and back of the case. Still using the same CableMod Pro coiled keyboard cable (midnight black). The keycaps are PBTfans WOB (white on black simple icon base). Really enjoy how they feel and sound, not a single complaint. I swapped the stock steel plate for a Wooting PC switch plate in black (plastic). It's quieter than steel and softer on the fingers when bottoming out. I replaced the old o-ring setup with a Wooting friction fit pad, which also cuts down on noise. I swapped the original Jades for Gateron Magnetic Jade Pros. They have a bit of a bassier tone. The original Magnetic Jades, when lubed, sound similar to unlubed Jade Pros; with lube on the Jade Pros they get quieter with less high-pitched noise. Overall maybe a 5–10% difference, enough that I justified upgrading. One day I may try another silicone pour in the Tofu Redux. For now I'm happy with this build after using the same setup for a few years.

Mods & write-up

Sound dampening

Silicone mold kit · $10.99

More photos

Started with the stock Wooting foam in the aluminum GH60 case. It sounded okay, but there was still a lot of room left in the case, which caused some case ping. I wanted something that fills more of the GH60 volume.

Sound comparison, Magnetic Jades vs Lekker switches:

For the silicone pour, I covered all holes in the GH60 with masking tape, including standoffs. Stirred the silicone with a plastic fork in a solo cup for a little over six minutes, then let it cure overnight (~12 hours). I trimmed extra material around the standoffs with an X-Acto knife, it doesn’t look perfect, but it sounds like what I was hoping for. The board is also noticeably heavier.

Idea from: How to Make a Tofu 60 Silicone Dampener · Serendipity

Cable

CableMod Pro coiled keyboard cable (midnight black) · $29.90

Tachyon mode works fine with this cable. I run keyboard brightness pretty low at 8% so I can still see the white PCB plate; you could run it higher.

Switches

Gateron Magnetic Jades · $56.00

I upgraded to Gateron Magnetic Jade switches after using hand-lubed Lekker switches with 50g springs from Wooting. The Magnetic Jades feel great and have a shorter travel distance, nice for CS2 counter-strafing with less room for error.

Switch lubing

Wooting lubricant set + toolkit · $34.99 bundle

I used both the switch lube set and toolkit from Wooting, no complaints.

Not sure exactly how long it took; my phone died right after I started, so I put on vinyl records and made it through a little over 4–5 albums before I was done.

Photo is from original Lekker lubing; I’ve since lubed the Lekkers again and the Magnetic Jades.

Case

GH60 aluminum keyboard case (black) · $79.00

Really happy with this case for the price, it adds a lot of weight.

If you plan on burger mounting with this case, pick up appropriate hardware for that style of mount.

Gummy O-ring

Ringer Keys replacement O-rings · $7.00

White 185mm OD × 3.5mm CS silicone 50A durometer, suggestion from BadSeed Tech.

Keycaps (black WOB + red Crosshair)

PBTfans WOB · $84.00

Using PBTfans WOB simple base with the Crosshair Alpha add-on kit. Love the set, the extra red accent color makes the caps stand out on the black case.

Some photos on the site still show YMDK Katakana keys on the edges (slightly different black vs PBTfans). See the sound-test video for a more current look.
