Memory

First player — iPod nano (6th gen), model A1320, no. 2317

Apple — iPod nano (6th generation) tech specs | reference

The small clip-style nano was my first device just for music. I had an iHome dock for it and listened to a lot of Michael Jackson—multiple albums—because an iTunes card did not go very far at first, so MJ plus a few other songs dominated early playlists. Later it filled up with Skrillex and more as the library grew.
